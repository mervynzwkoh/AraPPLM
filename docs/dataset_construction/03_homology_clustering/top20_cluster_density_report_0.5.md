This report evaluates the internal cohesion, clique density $f_k(\theta)$, and representative-to-member similarities across the **20 largest clusters** generated at sequence identity threshold(s) $\theta \in \{0.50\}$ and reciprocal coverage threshold(s) $c_{\min} \in \{0.50, 0.60, 0.70, 0.80, 0.90\}.

## 1. Metric Formulations

### A. Intra-Cluster Clique Density ($f_k(\theta)$)
For a cluster $k$ containing $n_k$ interaction pairs, the total number of distinct pairwise comparisons is $\binom{n_k}{2} = \frac{n_k (n_k - 1)}{2}$. The **intra-cluster clique density** $f_k(\theta)$ is defined as:

$$
f_k(\theta) = \frac{\#\{(P_i, P_j) : S(P_i, P_j) \ge \theta\}}{\binom{n_k}{2}}
$$

- **$f_k(\theta) = 1.0$ (100%)**: Represents an **ideal complete clique**, where every interaction pair is mutually similar ($\ge \theta$) to every other interaction pair in the cluster.
- **$f_k(\theta) < 1.0$**: Indicates a **star / hub-and-spoke topology**, where peripheral pairs share $\ge \theta$ similarity with the cluster representative $P_{\text{rep}}$, but some divergent pairs at the periphery fall below $\theta$ relative to each other.

### B. Representative-to-Member Similarity
Measures how tightly member interactions cluster around the cluster centroid / representative $P_{\text{rep}}$ ($n_k - 1$ comparisons):
- **$\min_{P_i \neq P_{\text{rep}}} S(P_{\text{rep}}, P_i)$**: The cluster radius / minimum similarity of any recruited member to the representative (bounded below by $\theta$).
- **$\text{mean}_{P_i \neq P_{\text{rep}}} S(P_{\text{rep}}, P_i)$**: The average similarity between the representative interaction and all recruited member interactions.
